# Calculadora Básica en Python

## Descripción
Este script de Python implementa una calculadora básica que permite realizar las cuatro operaciones aritméticas fundamentales: suma, resta, multiplicación y división. El usuario selecciona la operación deseada y proporciona los dos números a operar.

## Funcionalidades
* **Selección de operación:** El usuario elige la operación a realizar entre suma, resta, multiplicación y división.
* **Entrada de números:** El usuario ingresa los dos números que desea operar.
* **Realización de cálculos:** El script realiza la operación seleccionada y muestra el resultado.

## Cómo utilizar
1. **Ejecutar el código:** Ejecuta el script de Python en tu terminal.
2. **Seleccionar operación:** Ingresa el número correspondiente a la operación deseada (1 para suma, 2 para resta, etc.).
3. **Ingresar números:** Introduce los dos números que quieres operar.
4. **Ver resultado:** El script mostrará el resultado de la operación.

## Tecnologías Utilizadas
* **Python:** Lenguaje de programación principal utilizado para desarrollar el script.
* **Entrada y salida:** Se utilizan `input()` y `print()` para interactuar con el usuario.
* **Conversión de tipos:** Se utiliza `int()` para convertir las cadenas de entrada a números enteros.
* **Condicionales:** Se utilizan estructuras `if`, `elif` y `else` para seleccionar la operación a realizar.

## Aprendizajes clave
* **Programación básica en Python:** Variables, tipos de datos, operadores, estructuras de control (condicionales).
* **Entrada y salida de datos:** Interacción con el usuario a través de la consola.
* **Conversión de tipos:** Cambio de un tipo de dato a otro (en este caso, de cadena a entero).
* **Lógica de programación:** Resolución de problemas de forma estructurada y secuencial.
